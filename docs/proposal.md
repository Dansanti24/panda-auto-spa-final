# Panda Auto Spa — Project Proposal

A full-stack booking website for Panda Auto Spa, a premium car detailing business in Allentown, PA.

## Tech Stack
- Frontend: Next.js 14, React, CSS Modules
- Backend: Next.js API Routes
- Database: MongoDB + Mongoose
- Auth: JWT

## Features
- Services and pricing display
- Appointment booking form
- User authentication (register/login)
- Contact form
- Admin dashboard
